// Carabina estilo AR-15 "MK16 URG-I", 5.56x45mm NATO, pente STANAG de 30.
// Script portado do mod antigo e AJUSTADO para o RTN - o que mudou e por que:
//   primary_ammo  "m16" -> "5.56"   o tipo foi renomeado no ammodesc.txt
//   nextattack    0.1 -> 0.075      800 tiros/min (carabina curta de AR-15 cicla
//                                   na faixa de 700-950; a M4 do jogo usa 750)
//   PunchAngle*   um pouco menor     5.56 e leve e a arma e de alto desempenho
//   SpreadRangeIS 0..0.1 -> 0.1..0.4 mira muito precisa (intencao original do
//                                   mod antigo), mas sem cone zero - nenhuma arma
//                                   real tem dispersao nula
//   hudsprite     .tga 200x62        pipeline atual (ver o cabecalho do icone abaixo)
//   hudsprite ammo/ammo2 removidos   apontavam pro atlas 640hud7 do Paranoia 2
//   bucket_position 6 -> 4           MAX_WEAPON_SLOTS e 5 aqui (P2 usa 10); o
//                                   parser clampava o 6 para 4 de qualquer jeito
// Os numeros de recuo/dispersao sao ajuste de jogo (nao dado de fabrica) - calibrar em jogo.
// Modelos: p_ar15 e p_m3 vem do mod antigo (conferir se existem; o worldmodel
// aponta pra um "p_", que costuma ser o modelo de maos, nao o do chao).
